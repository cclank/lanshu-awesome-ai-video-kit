### ve-021 · Veo 3.1 原生对白与口型同步写法（120ms lip-sync）
`veo-3` `dialogue-driven` `dialogue` `lip-sync` `rain` · [www.atlascloud.ai](https://www.atlascloud.ai/blog/ai-updates/veo-3.1-prompt-guide)

```
Dialogue Structure: "Character [Description] says '[Exact Quote],' [Tone Adjective], [Sync Timing]."

Example: A middle-aged detective says 'I told you not to come here,' weary and gravelly tone, 120ms lip-sync delay.

Use quotation marks for spoken lines: putting the exact dialogue in quotes (says, "...") gives the model a clear start and stop point. List ambient sounds (like rain tapping or cafe murmur) at the end of the prompt so the engine does not blend environmental noise into the main speech track.
```
